# グラビア プロンプト

プロンプト文を組み立てるローカル画面です。画像生成はしません。

`prompts/gravure/start.cmd` をダブルクリックすると起動し、ブラウザで `http://127.0.0.1:7871` を開きます。ウィンドウは開いたままにしてください。閉じると画面も止まります。

```powershell
cd D:\tools\musubi-tuner
uv run --no-project prompts/gravure/app.py
```

`--no-project` 付きなので、学習用の torch は sync しません。依存は Gradio だけです。Markdown を足したあとは、画面を起動し直すと候補に入ります。

## 画面

「カテゴリ別件数」タブで、登録総数、パーツ別、衣装・ヘア・アクセサリの系統別、背景の場所と人の入り別、季節別、小道具の件数を確認できます。生成画面の選択状態に関係なく、起動時に読み込んだ候補を数えます。複数タグの候補は各区分に計上します。Markdownの変更後はアプリを起動し直してください。

- **枚数** と **seed**。同じ seed とオプションなら同じ結果です
- **人物**。空なら人物パートは出ません。書いた文がそのパートになります
- **カメラ**、**構図**、**ポーズ**、**表情**、**ライティング**。選んだ候補から抽選します。未選択ならそのパートは出ません。カメラは角度と色の空気まで書いた長い文です。表情は顔の感情だけです
- **季節**。未選択は通年だけです。選ぶと、その季節の光だけになります。背景は、その季節の候補がある場所だけ季節のものになり、ない場所は通年のままです。衣装とヘアには通年にその季節が足されます
- **衣装**、**髪型**。オンにした系統だけが候補です。未選択なら出ません。部位別コーディネートは別欄で選びます。系統はホーズ、テーラード、ニット、ドレス、イブニング、水着、カジュアル、きれいめ、メイド、和装、ステージ、クラシカル、ガーリー、モチーフです
- **小道具**。オフ、またはポップ。ポップのときは最大数まで入れます
- **背景**。選んだ場所から抽選します。**人** は無人、人が少ない、人が多いです
- **固定**。そのスロットを指定ブロックにして、残りを回します

右欄は1本ずつ分かれたフォームです。解説、1行、パートにそれぞれコピーボタンがあります。解説は合成した内容の日本語です。ネガティブは別欄です。各カードの **生成** は、1行とネガティブをローカルの Forge（`/sdapi/v1/txt2img`）へ送り、返った画像をそのカードのプレビューに出します。生成中は steps、枚数、残り時間を出し、Forge が途中画像を返していればプレビューも更新します。画像をクリックすると拡大します。Forge 側に読み込まれているモデルを使います。幅・高さ・steps・CFG・Distilled CFG・sampler・画像seed・batch count は左の Forge 欄です。batch count は同じプロンプトを何枚続けるかで、1から8です。初期値は Euler a、8 steps、CFG 1、Distilled CFG 1.15、832×1216、batch count 1 です。プロンプトを作ったときの設定と結果、および Forge 欄は、同じブラウザの localStorage に残ります。

## ブロックの書き方

`prompts/gravure/` 以下の `*.md`（`README.md` を除く）を読みます。

```markdown
## 水着

slot: outfit
pool: swim
season: summer

**W1 — 黒のワンピース**

```
She wears a simple black one-piece swimsuit, bare legs, and is barefoot.
```
```

| 行 | 意味 |
|----|------|
| `slot:` | `camera` `shot` `pose` `outfit` `hair` `accessory` `prop` `background` `lighting` `negative` |
| `pool:` | `hosiery` `tailored` `knit` `dress` `evening` `swim` `casual` `neat` `maid` `wa` `stage` `classic` `girly` `motif`。小道具は `pop`。カンマで複数可 |
| `season:` | `spring` `summer` `autumn` `winter`。空なら通年。カンマで複数可 |
| `presence:` | 背景の人の入り。`none` `few` `many`。空なら無人 |
| `category:` | 背景の選択肢名。省略時は直前の `##` 見出し |
| `flag: toddler` | そのブロックは候補に入れない |

`slot:` と `pool:` は、次の `##` まで続く見出し側にも書けます。英語のコードブロックの直後に ` ```ja ` を書くと、画面の解説にその文が入ります。

幼児の服装そのものを指す見出し（`幼児`、`保育園`、`園児`）のブロックは読み飛ばします。子供っぽい見た目は `girly` か `motif` にし、画面でその系統をオンにしたときだけ使います。

## 演出・撮影質感

演出と撮影質感はそれぞれ1種類、初期値は「なし」です。撮影質感はヴィンテージフィルム・スマホ・古いコンデジなどの機材、レンズ、発色、描写をまとめた指定です。選ぶとカメラ候補や固定カメラから角度だけを残し、元のレンズ・色調・写真スタイルを置き換えます。カメラ候補の表示も角度名に変わります。「なし」は従来のカメラ指定です。角度・構図・ポーズは別に選べます。

直射フラッシュ付きの質感では、別途選んだライティングを出力せず、質感側のフラッシュを使います。背景や人物欄に書いた光・撮影指定は自動では除去しません。質感はプロンプト冒頭の独立したパートに入り、日本語解説にも反映します。強さは弱め・標準・強め。選択変更後は「プロンプトを作る」でカードを更新してください。Forgeの「生成」はカードにある英語を送ります。

旧印刷効果の候補は廃止し、保存された旧選択とそのカードは再利用しません。ほかの設定は維持します。撮影質感の再現度は画像生成モデルによって変わります。

内部の `slot: finish` は撮影質感、`slot: effect` は演出です。カメラブロックに `view:`（英語の角度）と `view_ja:`（その日本語解説）を書くと、撮影質感と組み合わせたときの角度に使います。未指定なら元のカメラ文を混ぜず、角度指定を省略します。撮影質感ブロックの `flag: flash` はライティングを置き換えます。

## 部位別コーディネート

衣装は衣服本体、髪型は髪の形だけに分離しました。髪飾り・耳飾り・首元・手首・手と手袋・脚まわり・靴・その他の装飾とバッグを個別に選べます。

- コーデにおまかせ：選ばれた衣装・髪型の `wear:` 参照を使います。指定がない部位は追加しません。同じ部位に両方の指定がある場合は衣装を優先します。
- なし：装飾を付けない指定を出します。靴は裸足、脚まわりはストッキング・タイツ・靴下などを付けない指定です。
- ランダム：その部位の候補から1件選びます。髪飾りは髪型、それ以外は衣装の選択系統で絞り込み、季節は通年と選択季節を使います。候補0件なら追加しません。
- 個別指定：選んだ候補で置き換えます。系統と季節の絞り込みより優先します。

旧アクセサリの一括抽選は廃止しました。保存済みの衣装・髪型などは維持し、古いカードは再生成する扱いにしています。部位別の選択も保存します。衣服と一体の帯・ベルト・襟のボウ・ケープの留め具は衣装に残します。ポーズや人物欄へ直接書いた装飾品は自動では除去しません。

追加スロットは `hair_accessory` `earrings` `neckwear` `wristwear` `handwear` `legwear` `footwear` `extra_accessory` です。元コーデの部品は各衣装・髪型ブロックの `wear: footwear/部品ID,legwear/部品ID` のような参照で指定します。

## コスプレパーツ

猫耳・バニー耳・角は「髪飾り」、首輪は「首元」、猫の手は「手・手袋」です。「天使の輪」「背中・羽」「しっぽ」は独立欄で、耳と輪、羽としっぽを同時指定できます。各欄で個別指定、または対応する髪型・衣装系統にモチーフかステージを含めたランダム抽選ができます。ランダムはその部位の通常候補も含みます。元コーデに指定がない追加部位は、おまかせでは何も追加しません。既存の保存設定は維持し、新しい欄はおまかせになります。変更後はプロンプトを作り直してください。

## カードの一部だけ変更

各カードの「このカードの一部を変更」でパートを選び、「その部分だけ引き直す」を押すと、ほかのパートを保ったままプロンプトを変更します。画像は自動生成せず、そのカードの「生成」で新しく作ります。画像の局所編集ではないため、画像生成後の他の部分まで同じ見た目に保つ機能ではありません。

候補はカード作成時の系統・季節・カメラやポーズなどの候補選択・背景の場所と人の入りを使います。対象パートの固定と個別指定は解除して抽選し、現在の候補は除外します。左側の後からの変更は使いません。候補がなければ変更しない理由を表示します。衣装や髪型を変更しても、靴や装飾などほかの部位は変更しません。小道具は個数を維持します。撮影質感と演出はこの操作の対象外です。

部分変更したカードも保存します。旧カードには変更元の情報がないため、最初に「プロンプトを作る」で作り直してください。カードの1行・パート・解説を手編集した場合は、内容を失わないよう部分変更を止めます。

## コスチューム・プリセット

「コスチューム・プリセット」で定番の一式、または全プリセットからランダムを選べます。初期値は使わないです。プリセットは `slot: costume` の衣装本体と `wear:` の部位パーツ参照で構成し、衣装の系統・衣装固定より優先します。髪型・ポーズ・背景は維持します。コスチューム使用時は髪型に付随する装飾を引き継がず、プリセットの装飾を使います。

各部位の「コーデにおまかせ」はプリセットの指定を引き継ぎ、指定のない部位は追加しません。「なし」「ランダム」「個別指定」はプリセットより優先します。靴・首飾りなどは衣装文へ埋め込まず、部位単位で置き換えます。選択は保存されます。カテゴリ別件数にはコスチュームの系統別件数も表示します。

カードで衣装だけ引き直すと、コスチューム使用時は同じ系統の別の衣装本体から抽選します。装飾や足元は保つため、一式を別プリセットへ変えるときは左欄で選んでプロンプトを作り直してください。

コスチューム使用時の部位ランダムとカードの部位引き直しは、選ばれたコスチュームの系統（モチーフ・ステージ）から抽選します。一般衣装の選択系統には引きずられません。
